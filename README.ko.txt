로컬띵스 커뮤니티 — 삼성 가전, 클라우드 없이.

이 앱은 최신 삼성 가전을 집 안 네트워크에서 직접 제어합니다. Homey가 각 가전의 LAN 주소로 직접 통신하므로, 명령과 상태값이 SmartThings나 다른 클라우드를 거치지 않습니다. 집 밖으로 나가는 것이 없고, 인터넷이 끊겨도 그대로 동작합니다.

설정은 클라이언트 인증서를 한 번 등록하는 것으로 끝납니다. 삼성 가전은 인증서를 제시하는 로컬 제어기만 받아들이기 때문에, 컴퓨터에서 보조 스크립트로 인증서를 만들어 파일 두 개를 앱 설정에 붙여넣습니다. 이 인증서 하나가 집 안 모든 삼성 가전에 통용되므로 기기마다 반복할 필요가 없습니다. 그다음 가전 추가는 검색입니다. 앱이 로컬 네트워크를 훑어 응답하는 기기를 찾고 종류와 모델까지 확인해 목록으로 보여주므로 한 번만 선택하면 됩니다. 주소를 이미 알고 있다면 직접 입력할 수도 있습니다.

에어컨과 인덕션은 실제 기기로 검증했습니다. 에어컨은 전원, 희망 온도와 현재 온도, 운전 모드, 풍량, 풍향, 무풍을 비롯한 쾌적 모드, 공기청정, 자동 건조, 표시등과 엣지 라이팅, UV 살균, 부재 절전, 습도, 순간·누적 전력, 미세먼지, 필터 상태를 다룹니다. 인덕션은 구별 화력과 동작 상태, 잔열, 차일드락, 안전 자동 차단, 전력 사용량, 블루투스 온도 프로브를 보여줍니다. 조리 가전의 가열 제어는 의도적으로 읽기 전용입니다. 자동화가 원격으로 버너나 오븐을 켤 수 있어서는 안 되기 때문입니다.

가전이 지원하는 경우 상태는 폴링 주기를 기다리지 않고 변화하는 즉시 푸시로 도착하며, 가전이 구독을 받아주지 않을 때만 폴링으로 대체됩니다. 플로우 카드로 알람 코드 발생, 필터 점검 필요, 동작 완료에 반응할 수 있고, 기기가 푸시로 상태를 받고 있는지 조건으로 확인할 수 있습니다. 가전의 IP 주소가 바뀌면 앱이 시리얼 번호로 다시 찾아내므로 재등록이 필요 없고, 시리얼이 일치하지 않는 가전은 제어를 거부합니다. 같은 모델 두 대가 주소를 서로 바꿔도 서로를 조작하는 일이 생기지 않습니다.

냉장고, 세탁기, 건조기, 식기세척기, 공기청정기, 제습기, 오븐, 레인지, 전자레인지, 가스쿡탑, 주방 후드, 정수기, 청정스테이션, 에어드레서도 인식합니다. 이 종류들은 이 앱이 기반한 Home Assistant 통합에서 이식했지만 실제 기기로 확인하지는 못했습니다. 출발점으로 생각해 주시고, 사용해 보신 결과를 알려주시면 반영하겠습니다.

로컬 프로토콜을 지원하는 가전만 연결할 수 있습니다. 대략 2022년 이후 모델이 이를 지원하며, 그 이전 모델과 일부 최신 모델은 로컬 포트를 아예 열지 않아 브랜드와 무관하게 이 방식으로는 제어할 수 없습니다. 펌웨어 13 이상의 Homey Pro가 필요합니다.
