LocalThings Community — Samsung appliances, no cloud.

This app controls newer Samsung appliances directly over your own network. Homey talks to each appliance on its LAN address, so commands and readings never travel through SmartThings or any other cloud service. Nothing leaves your home, and nothing stops working when the internet does.

Setup asks for a client certificate once. Samsung appliances only accept a locally connected controller that presents one, so you generate it on a computer with a helper script and paste two files into the app's settings. That single certificate then covers every Samsung appliance in the house — you do not repeat it per device. From there, adding an appliance is a search: the app sweeps your local network, identifies what answers, and shows each appliance with its type and model so you can add it with one tap. If you already know an address you can type it instead.

Air conditioners and induction cooktops are verified against real hardware. An air conditioner exposes power, target and current temperature, operating mode, fan speed, airflow direction, Wind-Free and the other convenient modes, air purify, auto clean, panel and edge lighting, UV sterilisation, absence power saving, humidity, current and cumulative power, dust readings and filter status. An induction cooktop reports per-burner power level, state and residual heat, child lock, safety shutoff, power use, and a Bluetooth probe's temperature. Heat controls are deliberately read-only on cooking appliances: an automation must never be able to start a burner or an oven.

Where the appliance supports it, state arrives by push the moment it changes rather than on a polling interval, and the app falls back to polling only if the appliance will not subscribe. Flow cards let you react to an alarm code, a filter needing attention or a cycle finishing, and check whether a device is receiving push updates. If an appliance changes IP address, the app finds it again by serial number without re-pairing, and it refuses to control an appliance whose serial no longer matches — so two identical units swapping addresses cannot end up driving each other.

The app also recognises refrigerators, washers, dryers, dishwashers, air purifiers, dehumidifiers, ovens, ranges, microwaves, gas cooktops, range hoods, water purifiers, vacuum clean stations and AirDressers. Those types are ported from the Home Assistant integration this app is based on, but have not been tested against real hardware, so treat them as a starting point and please report what you find.

Only appliances with the newer local protocol can be reached. Roughly 2022 and later models expose it; older ones and some current models keep no local port open at all and cannot be controlled this way, whatever their brand. Requires Homey Pro with firmware 13 or newer.
